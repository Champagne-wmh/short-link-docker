# 短链接系统 short-link

一个**简历级 Java 后端项目**，用「发号器 + Base62 + 302 跳转」实现短链的生成与跳转闭环。项目集成了 RabbitMQ 异步统计，并已实现完整的 **Docker 多阶段构建与容器化部署**。

> 对应需求文档：《短链接系统 需求说明书 v1.0》

## 一、技术栈

| 层次 | 技术 | 版本 |
|---|---|---|
| 语言 | Java | 17（LTS） |
| 框架 | Spring Boot | 3.2.5 |
| ORM | MyBatis-Plus | 3.5.7 |
| 存储 | MySQL | 8.0 |
| 消息队列 | RabbitMQ | 3.x（含死信队列） |
| 接口文档 | Knife4j（springdoc） | 4.4.0 |
| 构建 | Maven / Docker | 3.9.9 / 多阶段构建 |

## 二、已实现功能（V1）

- [x] **短链生成**：号段发号器生成唯一 ID → Base62 编码为短码 → 落库
- [x] **短链跳转**：302 临时重定向（保证每次点击都回到后端，可统计）
- [x] **自定义短码**：4-16 位字母数字，唯一索引兜底防冲突
- [x] **有效期管理**：永久 / 自定义到期，惰性删除（跳转时判断）
- [x] **异步统计**：点击跳转时发送 RabbitMQ 消息，消费端异步落库（含手动 ACK 与死信处理）
- [x] **接口文档**：Knife4j 中文界面，访问 `/doc.html`

## 🐳 三、Docker 容器化部署（核心亮点）

本项目使用 **多阶段构建（Multi-stage Build）** 将 Spring Boot 应用打包为极简镜像，剥离了源码与 Maven 构建工具，大幅减小了镜像体积并提升了安全性。

在项目根目录执行：
